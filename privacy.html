Privacy Policy

Last updated: November 10, 2026

About Vultr Backup

Vultr Backup is a personal, non-commercial utility used by its owner to securely back up server configurations, application files and databases to Google Drive.

Google Drive Access

The application uses Google OAuth authorization with the drive.file scope to create, access and manage backup files authorized for the application.

Data Protection

Backup contents are encrypted locally using Restic before being uploaded to Google Drive. Encryption passwords are not transmitted to Google Drive as part of the backup.

Data Sharing

The application does not sell or share backup contents with advertisers or other users. Encrypted backup files are stored in the owner's Google Drive account.

Data Retention and Control

The owner controls backup retention and deletion. Google account access can be revoked through Google Account security settings.

Website Privacy

This informational website does not operate advertising, analytics or visitor registration. It is hosted through GitHub Pages.
